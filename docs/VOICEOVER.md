# Nims demo: voice-over script

Timed to the final `nims-demo-silent.mp4` (88.9 s). Every start and end time below was measured from a recording in which each action waits for its line, so the picture and the narration are locked. `nims-demo.mp4` is the same video with a computer voice (macOS "Samantha") as a placeholder track, so you can hear the timing.

**280 words, read at about 165 words per minute.** The lines run back to back with a 0.35 s breath between them (0.77 s before the sale line), so there is no stretch of picture without narration. If you read slower than the placeholder voice, a line will run past its end time into the next one: trim words, don't speed up.

## Reading notes
- Don't read numbers off the screen (prices, balances); they change with every recording.
- The last line mentions NEAR testnet. The video shows no chain scene, so it is a spoken claim only. The README covers it: settlement runs in the background and each player has a proof link in the News panel.
- To re-time after editing a line: change its text in your recording, keep its length within about 0.3 s of the "Length" column, and it will still fit its slot.
